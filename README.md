# Oil Spill & Vessel Attribution Backend

This is the backend engine for the NTRO oil spill detection challenge. It handles drift hindcasting/forecasting (using ocean currents/winds) and AIS vessel spatio-temporal correlation.

## Tech Stack
* **Framework:** FastAPI (Python 3.11)
* **Geospatial Math:** GeoPandas, Xarray, Shapely
* **Database:** PostgreSQL 15 + PostGIS

## How to Run Locally

1. Install [Docker Desktop](https://www.docker.com/products/docker-desktop/).
2. Ask the backend lead for the `.env` file and place it in the root directory.
3. Open your terminal in this directory and run:
   ```bash
   docker compose up --build
   ```

## Data requirements

Several runtime data paths are excluded from version control (`.gitignore`) due to size and dynamic generation, but are required by backend services to serve traffic properly:

### 1. `json_output/`
* **Purpose**: Required by `SpillCatalogService` and demo attribution endpoints. Contains detection polygons, validation metrics, and attribution catalogs (specifically `json_output/validation/detection_attribution_results.csv`).
* **How to obtain/mount**: Generated by ML pipeline ingestion/processing scripts (e.g., `scripts/ingest_ml_outputs.py` or synthetic scenario generators) or mounted via Docker volume at `/app/json_output`.

### 2. `data/weather/raw/` (and `data/weather/raw/yearly/`)
* **Purpose**: Required by `WeatherService` for ERA5 atmospheric wind velocity NetCDF files (10m $u$ and $v$ wind velocity vectors, e.g. `era5_wind_2019-*.nc`).
* **How to obtain/mount**: Downloaded from the ECMWF Copernicus Climate Data Store (CDS) via `cdsapi` (see `scripts/weather/download_era5.py` and `CDSAPI_KEY` in `.env`) or mounted into container volumes at `/app/data/weather/raw/yearly`.

### 3. `data/ocean/raw/` (and `data/ocean/raw/yearly/`)
* **Purpose**: Required by `WeatherService` for CMEMS Mediterranean hydrodynamic ocean current NetCDF files ($u_o$ and $v_o$ eastward and northward surface currents, e.g. `med_currents_2019-*.nc`).
* **How to obtain/mount**: Downloaded from Copernicus Marine Service (CMEMS) or mounted into container volumes at `/app/data/ocean/raw/yearly`.

*Note*: During startup, `app/main.py` checks for the presence of these directories. If any directory is missing, a descriptive `logger.error` is emitted without terminating the process, allowing volume mounts or degraded execution.
